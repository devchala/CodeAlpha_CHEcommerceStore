# CodeAlpha E-commerce Store

A full-stack e-commerce project for the CodeAlpha Full Stack Development Internship.

## Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express.js
- Database: MongoDB
- Authentication: JWT

## Project structure

```text
CodeAlpha_EcommerceStore/
├── client/
└── server/
```

## Setup

1. Open the project in VS Code.
2. Open a terminal in `server`.
3. Run `npm install`.
4. Copy `.env.example` to `.env` and add your MongoDB URI and JWT secret.
5. Run `npm run dev`.

The frontend can be opened through the backend after the integration step.
